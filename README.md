## 📖 项目介绍 (Introduction)

**AgriFlow** 是一款面向现代畜牧企业的 **SaaS 级全流程溯源管理平台**。系统致力于解决传统养殖场景中存在的“数据孤岛”、“账实不符”及“溯源断层”痛点。

通过数字化手段，AgriFlow 实现了从**批次入栏、动态养殖、病历追踪、检疫登记到最终出栏**的全生命周期闭环管理。结合可视化数据大屏，为企业提供实时的生物资产监管与经营决策支持。

## ✨ 核心亮点 (Key Features)

### 1. 🛡️ 复杂库存的一致性治理
针对高频的“动物入栏/调仓”场景，系统摒弃了传统的单表更新模式：
- **事务级联动**：设计原子化业务逻辑，在变更动物档案时，自动锁定关联栏圈（Hurdles）并计算物理存栏。
- **动态状态机**：引入自动校验机制，根据实时存栏量与容量阈值，动态推演栏圈的 `饱和/未满` 状态，无需人工干预，确保**库存准确率 100%**。

### 2. 🔗 溯源流程闭环 (Traceability Loop)
打通养殖与销售端的数据壁垒，防止合规风险：
- **反向状态同步**：构建检疫业务回调机制。当《检疫合格证》录入完成后，自动触发**养殖批次**的状态流转（养殖中 -> 已检疫），实现业务流程自动化。
- **防御性逻辑校验**：在基础设施管理层实施严苛的逻辑删除校验，防止因误删栏舍导致的核心溯源链路断裂。

### 3. 📊 高精度数据大屏
- **金融级计算精度**：底层重构数据清洗逻辑，统一采用 `BigDecimal` 处理所有销量与金额统计，消除浮点数计算误差。
- **时序数据补全**：针对稀疏的业务数据设计 Zero-Filling 策略，保障可视化图表的连续性与鲁棒性。

## 🛠️ 技术栈 (Tech Stack)

| 模块 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **核心框架** | Spring Boot 2.7 | 快速构建微服务就绪架构 |
| **持久层** | MyBatis + PageHelper | 灵活的 SQL 映射与分页处理 |
| **数据库** | MySQL 8.0 | 业务数据存储 |
| **连接池** | Alibaba Druid | 高性能连接池与 SQL 监控 |
| **安全认证** | JWT (JSON Web Token) | 无状态单点登录与拦截器鉴权 |
| **API 文档** | Knife4j (Swagger 增强) | 接口文档自动生成与调试 |
| **工具链** | Maven, Git, Lombok | 项目构建与版本控制 |

## 📂 项目结构 (Structure)

```text
com.agriflow.product_source
├── config          // 全局配置 (Web, Swagger, Interceptor)
├── controller      // 控制层 (Restful API)
├── service         // 业务逻辑层 (事务控制, 状态流转)
│   └── impl        // 核心业务实现 (ManagerAnimalServiceImpl等)
├── dao             // 数据访问层 (Mapper接口)
│   └── ext         // 扩展Mapper (处理复杂级联查询)
├── pojo            // 实体类
│   └── ext         // DTO/VO 扩展对象 (如 ManagerAnimalExt)
├── interceptor     // 拦截器 (JWT 校验)
├── exception       // 全局异常处理 (GlobalExceptionHandler)
└── utils           // 工具类 (JwtUtil, Result封装)
